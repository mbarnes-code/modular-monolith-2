# Legacy System Analysis

Use evidence-based classification with required proof:

## Analysis Templates by System Priority

### CRITICAL Systems (Revenue/Operations Blocking)
- **Template**: `project-analysis-template.md` (Full 13-section)
- **Proof Required**: Revenue loss OR operations stoppage docs
- **Output**: `project-analysis-[system].md`

### IMPORTANT Systems (Customer Experience Impact) 
- **Template**: `project-analysis-condensed-template.md` (Sections 1-5, 11-12)
- **Proof Required**: Customer metrics OR workflow degradation data
- **Output**: `project-analysis-condensed-[system].md`

### LOW-IMPACT Systems (Business Continues Normally)
- **Template**: `project-analysis-summary-template.md` (Sections 1-2, 12)
- **Proof Required**: 24+ hour business continuity evidence
- **Output**: `project-analysis-summary-[system].md`

Always create: `ai-context-summary-[system].md` for ALL systems
