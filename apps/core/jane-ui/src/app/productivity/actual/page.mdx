## Key Features

### 🔒 Privacy-First Design

- **Local data storage** - Your financial data stays on your device
- **No cloud dependency** - Works completely offline
- **Open source** - Transparent and auditable code
- **Self-hostable** - Optional sync server you can run yourself

### 💡 Smart Budgeting

- **Zero-based budgeting** - Assign every dollar a purpose
- **Goal tracking** - Save for specific targets with progress tracking
- **Flexible categories** - Organize expenses your way
- **Budget templates** - Start quickly with proven budgeting methods

### 📈 Powerful Analysis

- **Real-time reports** - Income, expense, and net worth tracking
- **Custom date ranges** - Analyze any time period
- **Category insights** - See where your money really goes
- **Trend analysis** - Spot patterns in your spending

### 🔄 Bank Integration

- **Automatic import** - Connect bank accounts for seamless sync
- **Transaction matching** - Smart reconciliation with manual review
- **Multiple accounts** - Credit cards, checking, savings, investments
- **International support** - Works with banks worldwide

## Getting Started Guide

### 1. Create Your First Budget

1. **Set up categories** - Organize your expenses (Housing, Food, Transportation, etc.)
2. **Add accounts** - Link your bank accounts or add them manually
3. **Import transactions** - Bring in your transaction history
4. **Assign categories** - Categorize transactions to see spending patterns
5. **Set budget amounts** - Allocate money to each category

### 2. Daily Workflow

- **Check daily** - Review new transactions and categorize them
- **Weekly review** - Assess category performance and adjust as needed
- **Monthly planning** - Set next month's budget based on previous patterns
- **Quarterly analysis** - Deep dive into trends and goal progress

### 3. Advanced Features

- **Rules and automation** - Automatically categorize recurring transactions
- **Split transactions** - Handle complex expenses across multiple categories
- **Transfer tracking** - Monitor money movement between accounts
- **Scheduled transactions** - Plan for recurring income and bills

## Technical Details

### System Requirements

- **Browser**: Chrome 88+, Firefox 85+, Safari 14+, Edge 88+
- **Storage**: 100MB+ free space for local database
- **Memory**: 2GB+ RAM recommended for large transaction histories
- **Network**: Optional for bank sync and updates only

### Data Security

- **Encryption**: All data encrypted at rest and in transit
- **Backup**: Built-in backup and restore functionality
- **Export**: CSV and JSON export options
- **Migration**: Import from Mint, YNAB, and other tools

### Self-Hosting Options

- **Actual Server**: Run your own sync server for multi-device access
- **Docker support**: Easy deployment with container images
- **API access**: Full REST API for custom integrations
- **Plugin system**: Extend functionality with custom modules
